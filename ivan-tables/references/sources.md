# Изученные источники

Дата просмотра: 5 ноября 2026 года. Это происхождение проектных решений, а не обязательные зависимости. Инструкции скилла написаны самостоятельно; чужие скиллы, код, шаблоны и данные в пакет не включены. Ссылки ведут на изменяемые ветки: перед заимствованием конкретных файлов повторно проверь содержание и лицензию.

## Общий скилл для Excel от Anthropic

[anthropics/skills — xlsx](https://github.com/anthropics/skills/blob/main/skills/xlsx/SKILL.md)

Универсальная работа с файлами Excel: создание, правки, формулы, пересчёт, сохранение соглашений исходного файла. Есть отдельный раздел для финансовых моделей. Полезен как пример внимания к корректности формул и редактированию существующих книг; предметных правил планирования отпусков и загрузки здесь недостаточно.

Не переносить целиком: он задаёт собственные библиотеки и среду исполнения, которые отличаются от штатных инструментов Codex. У `xlsx` есть отдельный [LICENSE.txt](https://github.com/anthropics/skills/blob/main/skills/xlsx/LICENSE.txt); не считать весь каталог автоматически распространяемым по общей лицензии репозитория.

## Рабочие реестры с проверками данных

[WHOISABHISHEKADHIKARI/sme-ops-system-builder — spreadsheet-manual-build](https://github.com/WHOISABHISHEKADHIKARI/sme-ops-system-builder/blob/main/skills/spreadsheet-manual-build/SKILL.md)

Самый близкий найденный пример по назначению: ручное ведение реестров, типы столбцов, настоящие выпадающие списки, фильтры и закрепление шапки, ограниченные правки. Он зависит от схем полей других модулей своего набора и существенно ограничивает самостоятельное проектирование полей и формул.

Использован как ориентир по удобству заполнения, а не как устанавливаемая основа: Ивану нужен самостоятельный скилл, который предлагает структуру по неполному брифу и может рассчитывать длительность, часы и загрузку.

## Пример Excel-книги с отпусками

[MrArshad07/Employee-Office-Management-System-Excel](https://github.com/MrArshad07/Employee-Office-Management-System-Excel)

В README описаны связанные листы сотрудников, посещаемости и отпусков. Для отпуска перечислены сотрудник, тип, начало, конец, количество дней и статус согласования; заявлены выпадающие списки и условное форматирование.

Рассматривался README как предметный референс. Сам `.xlsx` не скачивался, формулы и фактическая работа списков не проверялись. Это пример книги, не агентный скилл. Для задач Ивана не нужно воспроизводить весь кадровый учёт из этого проекта.

## Технический справочник функций Excel

[exceljs/exceljs — README](https://github.com/exceljs/exceljs/blob/master/README.md)

Документирует именованные диапазоны, проверки данных, закрепление областей, таблицы и условное форматирование. Полезен при выборе запасного инструмента для функции, недоступной штатным средством. Не является готовым скиллом или шаблоном планирования и не заменяет API выбранного инструмента. Подключать другую библиотеку следует только в рамках правил среды и реально необходимой функции.
